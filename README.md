# מונה הסקס של דגן (dagan-sex-counter.com) 🚀

אפליקציית מעקב מובייל פשוטה ומהנה למעקב אחר פעילות הסקס של דגן.
האפליקציה כתובה כולה בעברית (RTL), ללא צורך בהתחברות (Zero Auth), עם מנגנוני הגנה רב-שכבתיים מפני בוטים והצפות.

## 🌟 פיצ'רים מרכזיים

* **שער כניסה**: שאלה פשוטה וישירה: "האם אתה דגן?" (כן / לא).
* **מסך דיווח לדגן**:
  * בחירת תאריך ושעה (ברירת מחדל: "ממש עכשיו ⚡").
  * משך (זריז ⚡, קלאסי ⏱️, מרתון 🏆, או דקות בהתאמה אישית).
  * מיקום (בבית, ברכב, במלון, בטבע, וכו').
  * הערות וסיפורים חופשיים.
  * חגיגת קונפטי מלאה בסיום הדיווח.
* **מסך המונה (לסקרנים)**:
  * שעון עצר דינמי בזמן אמת: ימים, שעות, דקות ושניות שחלפו מאז האירוע האחרון.
  * באדג' סטטוס משעשע המשתנה בהתאם לזמן שחלף ("דגן בשיאו 🔥", "שגרה מבורכת 👍", "בצורת קלה 🏜️", "מצב חירום לאומי 🆘").
  * תקציר הפרטים מהאירוע האחרון.
* **יומן אירועים 📅**:
  * לוח שנה חודשי אינטראקטיבי עם סימוני ימים בהם נרשמו אירועים.
  * פירוט מלא של כל האירועים ההיסטוריים (תאריכים, זמנים, מיקומים והערות).
  * מדדי סטטיסטיקה (סה"כ אירועים, אירועים החודש).

## 🛡️ אבטחה והגנה מפני בוטים (ללא צורך באימות)

1. **שדה מלכודת דבש (Honeypot)**: שדה מוסתר הלוכד סורקי טפסים אוטומטיים ודוחה אותם.
2. **טוקן HMAC ובדיקת מהירות אנושית**:
   * טוקן חתום מונפק בעת פתיחת הטופס.
   * אם הטופס נשלח בפחות מ-1.5 שניות (מהירות בוט) — הבקשה נחסמת.
3. **הגבלת קצב של 30 דקות**:
   * כל כתובת IP (מוצפנת ב-Hash מאובטח) מוגבלת לדיווח בודד בכל 30 דקות.
4. **הגנת Flood**:
   * הגבלה ל-5 בקשות לכל 2 דקות למניעת התקפות הצפה.

## 🛠️ טכנולוגיות

* **Next.js 16 (App Router)** & **React 19** & **TypeScript**
* **Tailwind CSS v4** (עיצוב מודרני מותאם מובייל ו-RTL מלא)
* **PostgreSQL + Drizzle ORM** (תמיכה ב-Neon / Supabase / Vercel Postgres, עם fallback לקובץ מקומי בפיתוח)
* **canvas-confetti** (אפקט קונפטי מרהיב)
* **Lucide React Icons**

## 🚀 הרצה מקומית

```bash
# 1. התקנת תלויות
npm install

# 2. הרצת שרת פיתוח
npm run dev

# 3. בניית גרסת ייצור ובדיקה
npm run build
npm start
```

## ☁️ פריסה ל-Vercel

1. דחוף את המאגר ל-GitHub:
   ```bash
   git add .
   git commit -m "Initial release of dagan-sex-counter"
   git push origin main
   ```
2. חבר את הפרויקט ב-**Vercel Dashboard**.
3. הגדר במשתני הסביבה (Environment Variables):
   * `DATABASE_URL`: קישור למסד נתוני PostgreSQL (למשל מ-Neon, Vercel Postgres או Supabase).
   * `APP_SECRET`: מחרוזת אקראית מאובטחת להצפנה וחתימת טוקנים.
4. חבר את הדומיין **dagan-sex-counter.com** בהגדרות הדומיינים ב-Vercel.
